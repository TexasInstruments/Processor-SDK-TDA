# ONNX Operator Mappings:

<center>

| S. No. | Onnx Operator | TIDL Layer | Constraints |

| 1 | Conv | TIDL_ConvolutionLayer | <ul> <li> Only one variable input is allowed </li><li> Number of non-singleton variable input dimensions must be <= 4 </li><li> Weight tensor dimension must match the kernel_shape </li><li> Stride must be the same along both horizontal and vertical dimensions </li><li> Kernel size 3x3 with stride 3 is not supported in AM62A and AM67A </li><li> Kernel size greater than 7 with stride 2 is not supported </li><li> Depthwise (Fully Grouped) convolution is only supported for 1x3s1, 3x3s1, 3x3s2, 5x5s1, 5x5s2, 7x7s1 & 7x7s2 filters </li><li> Padding greater than input width is not supported for AM62A and AM67A </li><li> Stride 4 is only supported with Kernel size 11x11 </li><li> Input width less than MAX(Pad Left, Pad Right) is not supported for AM62A and AM67A </li></ul> | 
| 2 | AveragePool/GlobalAveragePool/MaxPool | TIDL_PoolingLayer | <ul> <li> Input should be variable </li><li> Number of non-singleton variable input dimensions must be <= 4 </li><li> GlobalAveragePool does not support plane size > 1024 </li><li> Only 1D and 2D GlobalAveragePool is supported </li><li> Pooling functionality is validated for 3x3,2x2 and 1x1 kernels with both stride 1 and stride 2 (horizontally and vertically), with the exception of 2x2 kernel with stride 1 </li><li> Only default dilations values (1,1) are supported </li><li> Number of outputs should be 1 </li></ul> |

| 5 | Max/Sum/Mod/Add/Mul/Div/Sub/Min | TIDL_EltWiseLayer | <ul> <li> Only 2 inputs are supported in Add/Mul/Sub/Div/Max/Min/Sum/Mod layers </li><li> Number of non-singleton variable input dimensions in Add/Mul/Sub/Div/Max/Min/Sum/Mod must be <= 6 </li><li> Both inputs as variable are supported in Sub only if firmware version >= 10_01_06_00 </li><li> The variable inputs in Add/Mul/Div/Sub/Max/Min/Sum/Mod layer must of be same dimensions or broadcast-able </li><li> Eltwise operator(Add/Mul/Div/Sub/Max/Min/Sum/Mod layer) is supported only with operands of similar dimensions or broadcast supported patterns of both inputs </li><li> 1D vector dimension should match with channel or width dimension </li></ul> |

| 7 | Softmax | TIDL_SoftMaxLayer | <ul> <li> Number of non-singleton variable input dimensions must be <= 6 </li><li> Only softmax along width and height axis is supported </li></ul> | 
| 8 | BatchNormalization | TIDL_BatchNormLayer | <ul> <li> Number of variable input dimensions must be <= 6 </li><li> training_mode = 1 is not supported </li><li> Scale, Bias, input_mean and input_var should be constant 1-D tensor of size same as input channel dimension </li></ul> |
